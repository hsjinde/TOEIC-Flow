# TOEIC Flow 完整功能系統 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成 TOEIC Flow 的全功能模組：SRS 單字卡、閱讀理解、錯題本、弱項能力統計、模擬考與章節教學。

**Architecture:** 基於 Next.js App Router 與 LocalStorage 全動態 State；無縫整合 `content/*.json` 資料；提供極簡、無摩擦、視覺質感一流的手機/桌機雙向練習體驗。

**Tech Stack:** Next.js 14+ (App Router) · React 18+ · TypeScript · Tailwind CSS · Vitest · Lucide React · Web Speech API
